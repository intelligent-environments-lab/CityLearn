Schema

A schema is the JSON configuration used to construct citylearn.citylearn.CityLearnEnv. It selects members, data files, equipment, observations, actions, reward and optional services.

Start from a public dataset’s schema, then change the sections required for your experiment. File paths are resolved against the dataset root. The Schema Reference gives the supported fields and defaults; Dataset Reference describes the referenced data.

Load a schema by dataset name, local path or a Python dictionary as shown in How to Load an Environment. Configuration is part of the simulator’s Python/JSON workflow. CityLearn UI is for exploring exported results.

Example structure

schema.json
├── simulation window and timestep
├── observations and actions
├── reward_function
├── buildings: data files, devices and electrical_service
├── electric_vehicles_def
└── optional community_market, demand_response, topology and robustness
