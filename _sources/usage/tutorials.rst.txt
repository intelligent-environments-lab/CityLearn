=========
Tutorials
=========

For current runnable examples, start with :doc:`../quickstart` and
:doc:`custom_controller`. The following longer-form tutorial explains the
building-control and reinforcement-learning concepts behind CityLearn:

* `CityLearn: A Tutorial on Reinforcement Learning Control for Grid-Interactive Efficient Buildings and Communities <https://www.climatechange.ai/papers/iclr2023/2>`_ :cite:p:`nweye2023citylearn`

This 2023 tutorial uses the interface and datasets of its release. For v3
configuration fields, wrappers and evaluation, use the current
:doc:`../guides/schema_reference`, :doc:`agents` and :doc:`../kpis`.
